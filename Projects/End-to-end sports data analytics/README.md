# 🏏 T20 World Cup Best Playing XI – Sports Analytics using Power BI

> **Building the Best T20 World Cup Playing XI using Data Analytics, Performance Metrics, and Power BI Visualization**

---

## 📌 Project Overview

Traditional cricket team selection often depends on expert judgment and subjective analysis.

This project introduces a **data-driven player selection framework** using **Power BI** to identify the **Best T20 World Cup Playing XI** based on measurable performance indicators.

The objective was to create a balanced squad capable of:

✅ Scoring **180+ runs consistently**
✅ Defending **150 runs effectively**
✅ Maximizing batting and bowling efficiency
✅ Reducing selection bias through analytics

---

## 🎯 Problem Statement

> *"We don’t know the strengths and weaknesses of our opponents — give me the best 11 from this planet."*

The challenge was to build a high-performing T20 squad by analyzing player performance across multiple categories and selecting players using predefined qualification rules.

---

## 🚀 Objectives

* Build a **Data-Driven Best XI**
* Analyze player performance using Power BI
* Create role-based selection criteria
* Compare players across batting and bowling KPIs
* Generate actionable sports insights

# 📊 Dashboard Sections

## ⚡ 1. Power Hitters / Openers

Selection Logic:

* Batting Average > 30
* Strike Rate > 140
* Boundary % > 50%
* Batting Position < 4

### Insights

✔ Aggressive starts increase overall scoring probability
✔ Strike rate + consistency matter more than total runs

---

## 🧱 2. Anchors / Middle Order

Selection Logic:

* Batting Average > 40
* Strike Rate > 125
* Avg Balls Faced > 20

### Insights

✔ Stability + acceleration balance innings
✔ Consistent middle order reduces collapse risk

---

## 💥 3. Finishers / Lower Order

Selection Logic:

* Batting Average > 25
* Strike Rate > 130
* Lower-order impact

### Insights

✔ Death-over acceleration changes outcomes
✔ Finishing ability creates competitive totals

---

## 🔄 4. All Rounders

Selection Logic:

* Strike Rate > 140
* Economy < 7
* Bowling Strike Rate < 20

### Insights

✔ Multi-skill players improve squad flexibility

---

## 🎯 5. Specialist Fast Bowlers

Selection Logic:

* Economy < 7
* Bowling Average < 20
* Dot Ball % > 40%

### Insights

✔ Dot-ball pressure directly improves wicket opportunities
